# Real Estate Powerhouse

Real Estate Powerhouse is a mobile-first React app for exploring 2025 Staten Island property sales from NYC Open Data. It offers a neighborhood market snapshot, live search and filters, and property details with nearby sales.

## API used

[NYC Citywide Annualized Calendar Sales Update](https://catalog.data.gov/dataset/nyc-citywide-annualized-calendar-sales-update) — NYC Department of Finance property sales, served through the NYC Open Data Socrata API (no API key needed).

## Run locally

```bash
git clone <your-repo-url>
cd real-estate-powerhouse
npm install
npm run dev
```

**Live site:** https://real-estate-powerhouse.netlify.app
